# 🪔 Bhanu Prakash & Anusha — Kalyanamasthu Wedding Website

A royal South Indian Temple-themed wedding website crafted with **React**, **Vite**, and **Tailwind CSS**, inspired by the sacred blessings of Lord Venkateswara Swamy & Goddess Padmavathi.

## ✨ Highlights & Features

1. **Sacred Temple Gopuram & Balaji Theme**:
   - South Indian Temple Gopuram architectures, Tirunamam (Shanku & Sudarshana Chakra), Kamadhenu, Kalash, Toran garland, and blooming lotuses.
   - Sacred Vedic Slokas in Telugu and English:
     > *"కళ్యాణాద్భుత గాత్రాయ కామితార్థ ప్రదాయినే | శ్రీమద్ వేంకటనాథాయ శ్రీనివాసాయ మంగళమ్ ||"*
   - Traditional auspicious colors: Sacred Temple Maroon, Royal Crimson, Shimmering Gold, and Chandan Sandalwood ivory.

2. **Special Tribute for the Bride (To Impress Anusha)**:
   - **"To My Beloved Bride, Anusha"** — An interactive wax-sealed royal love letter from Bhanu Prakash celebrating their Bangalore software engineer journey, her gentle kindness, and his 4 sacred lifelong promises (*Your Smile is My Home*, *Best Friend & Confidant*, *Championing Your Dreams*, *Eternal Love & Respect*).
   - Interactive wax seal breaking animation with flower petal shower!

3. **Complete Itinerary (Direct from Wedding Card)**:
   - **Reception & Dinner**: 28 November 2026 (Saturday) from 7:15 PM onwards at **Sai Aramam Function Hall**, Ganesh Circle, Main Road, Puttaparthi.
   - **Auspicious Muhurtham**: 29 November 2026 (Sunday) between 8:00 AM – 8:45 AM (Dhanassu Lagnam) at **Sai Aramam Function Hall**, Puttaparthi.
   - **Groom's Reception & Dinner**: 06 December 2026 (Sunday) from 11:00 AM at **P.R.C. Convention Centre**, G.T. Kandriga, Vedurukuppam Mandal, Chittoor Dist.
   - One-click Google Maps navigation routing & Google Calendar integration for every event.

4. **Interactive Devotional Elements**:
   - **Carnatic Shehnai & Nadaswaram Music Synth**: Built-in Web Audio API generator playing auspicious *Mohanam / Kalyanavasantham* melodies and tanpura drone.
   - **Ring Sacred Temple Bell (ఘంటానాదం)**: Authentic resonant bronze bell chime.
   - **Light the Sacred Diya (దీపారాధన)**: Digital oil lamp lighting with counter.
   - **Shower Akshathalu & Flower Petals**: Festive golden confetti and rose petals.
   - **Telugu / English Bilingual Toggle**: Instant switch between Telugu script and English.
   - **Interactive Guestbook & Wishes Wall**: Relatives and friends can post their blessings, stored locally in `localStorage`.
   - **RSVP Form**: Select events and number of guests attending.

## 🚀 Running the Project

```bash
# Navigate to the project directory
cd "bhanu&anusha"

# Install dependencies (already installed)
npm install

# Start local development server
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser to experience the site live.
